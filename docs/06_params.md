# 06 調整パラメータ候補

遊んでみないと決められない数値。実装では1か所（キャラデータ／共通設定）にまとめ、ここに書いた「初期値」で始めて、遊びながら「候補の幅」の中で調整する。
単位はフレーム（60fps）、距離はピクセル（画面幅 1280px 想定）。

## 共通

| 項目 | 初期値 | 候補の幅 | メモ |
|---|---|---|---|
| ヒットのけぞり：軽 / 中 / 重 | 14 / 18 / 24F | 各 ±4F | 打撃が当たった相手が動けない時間。長いほど当てた側が有利 |
| ガード硬直：軽 / 中 / 重 | 10 / 13 / 17F | 各 ±3F | ガードした側が動けない時間。短いほどガードした側が反撃しやすい |
| 連続技のダメージ補正 | 2発目以降 80% | 60〜90% | |
| ゲージ増加：当てた側 / 食らった側 / ガードさせた側 | ダメージの 0.8 / 0.4 / 0.3 倍 | — | ゲージ満タン＝1000。約50秒で満タンになるよう調整 |
| 必殺技・超必殺の削り | 本来のダメージの 20% | 10〜30% | |
| 投げ抜けの受付時間 | 掴まれてから 8F | 5〜12F | |
| ヒットストップ（当たった瞬間の一時停止） | 6F | 3〜10F | 手応えの演出。コミカルなら長めもアリ |
| 掴み成立〜投げ終わりの演出時間 | 40F | 30〜60F | 長すぎるとテンポが落ちる |
