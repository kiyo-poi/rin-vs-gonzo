# 01 コンセプト

ブラウザで動く、カジュアル・コミカルな2D格闘ゲーム。

## コンセプト

- 少ないボタンですぐ遊べる、笑える格闘ゲーム
- 対戦形式は2つ
  - 1台のPCで2人対戦（キーボードを2人で分け合う）
  - 1人 vs CPU（難易度：やさしい / ふつう / つよい）
- キャラはデータで定義し、あとから追加できる作りにする（最初は2体）

## 見た目

- キャラ画像はAI画像生成で作る
- 動かし方は「ポーズごとに1枚」＋「コードの演出」
  - 待機・歩き・パンチ・キック・被弾などの状態ごとに1枚
  - 伸び縮み、残像、効果線、揺れなどはコードで描いて動きを補う
  - 同じキャラを何枚も揃えて生成するのは難しいため、枚数を抑え演出で補う方針

## 音

- 効果音とBGMは無料素材を使う（ライセンス確認が必要）

## 操作方法

入力はキーボードのみ（ゲームパッド・タッチは対象外）。

| 操作 | 内容 |
|---|---|
| ← → | 移動（後ろ入力は後退。ガードにはならない） |
| ↑ | ジャンプ（↑で真上、↑＋→で前、↑＋←で後ろ） |
| ↓ | しゃがみ（上下段の概念はない。しゃがみ中のパンチ・キックでしゃがみ技） |
| パンチ | 通常攻撃 |
| キック | 通常攻撃 |
| 掴み | 投げ |
| 必殺 | 必殺技（ニュートラル / →＋必殺 / ↓＋必殺 の3種） |
| ガード | 押している間ガード |
| 必殺＋ガード同時押し | 超必殺技（ゲージ消費） |

- ガードを専用ボタンにしたのは、後ろに下がって間合いを取り、空振りに差し返す動きを使えるようにするため
- 上下段はなし。ガードボタンで全ての打撃を防げる
- ジャンプ中はパンチ・キックで空中攻撃が出せる（空中の掴み・必殺はなし）
- ダッシュはない（両キャラとも歩きだけ。接近は突進系の必殺技で行う）
- 1人あたり方向4＋ボタン5＝9キー、2人で18キー

## ゲージ

- 通常の必殺技（3種）は無料でいつでも使える
- 超必殺技だけゲージを消費する

## 勝敗条件

- 2ラウンド先取、1ラウンド99秒
- 体力0でラウンド負け
- 時間切れは体力が多い方の勝ち（キャラで体力の最大値が違うので、残り体力の割合で比べる）
- 時間切れで体力が同じ、または同時KOのときは両者に1勝
  - 両者リーチなら最終ラウンドへ
  - 最大5ラウンドまで。それでも決まらなければ引き分け

## 画面の流れ

```
タイトル → モード選択（2人対戦 / CPU戦）
            └ CPU戦なら難易度選択（やさしい / ふつう / つよい）
        → キャラ選択 → 対戦 → 結果
                               ├ 再戦
                               ├ キャラ選択へ
                               └ タイトルへ
```

- 対戦中は Esc でポーズ
- キー配置と技一覧は、タイトル画面・キャラ選択画面・ポーズ画面に表示する（専用の説明画面・設定画面は作らない）
