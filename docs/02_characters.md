# 02 キャラクター

最初は「スピード型 vs パワー型」の2体。キャラはデータで定義し、今後追加していく。
名前・数値はすべて仮。調整は実装して遊んでから行う。

## 共通の技構成

| 入力 | 技 |
|---|---|
| パンチ | 通常技 |
| キック | 通常技 |
| しゃがみ中パンチ | しゃがみ技 |
| しゃがみ中キック | しゃがみ技 |
| 掴み | 投げ |
| 必殺（ニュートラル） | 必殺技1（ゲージ消費なし） |
| →＋必殺 | 必殺技2（ゲージ消費なし） |
| ↓＋必殺 | 必殺技3（ゲージ消費なし） |
| 必殺＋ガード | 超必殺技（ゲージ消費） |
| ジャンプ中パンチ | 空中攻撃 |
| ジャンプ中キック | 空中攻撃 |

空中では掴み・必殺・超必殺は出せない。

## リン（仮）— スピード型

- 小柄なカンフー少女。黒髪のお団子2つ、赤いチャイナ服（仮）
- 体力は低め（850）、歩きが速い、ジャンプが軽い
- 素早い連打と蹴りで手数を稼ぐ

| 入力 | 技名 | 内容 |
|---|---|---|
| パンチ | ジャブ | 発生が速く、ダメージは低い |
| キック | 旋風脚 | リーチが長い |
| しゃがみパンチ | 下段掌 | 姿勢が低く、空中攻撃の一部をくぐれる |
| しゃがみキック | 足払い | 当たると相手がダウン |
| 掴み | 肩乗りエルボー | 相手の肩に飛び乗って肘を落とす。中ダメージ、着地後は相手の前 |
| 必殺 | 連拳 | パンチの連打。短いリーチで削る |
| →＋必殺 | 突進掌 | 前方へ素早く突進。接近手段 |
| ↓＋必殺 | 昇り蹴り | 上昇する対空技。出始め無敵、外す/ガードされると隙が大きい |
| 必殺＋ガード | 百裂連拳フィナーレ | 突進して乱打。コミカルな効果音と効果線 |
| ジャンプ中パンチ | 空中掌打 | 真横に掌を突き出す。空中戦用 |
| ジャンプ中キック | 飛び蹴り | 斜め下へ蹴る。飛び込み用 |

## ゴンゾー（仮）— パワー型

- 巨漢プロレスラー。黒いモヒカン、黒いパンツ、黄色いブーツ（仮）
- 体力は高め（1150）、歩きが遅い
- 一発が重く、掴みが強い

| 入力 | 技名 | 内容 |
|---|---|---|
| パンチ | チョップ | 遅いが重い |
| キック | ビッグブーツ | リーチが長い |
| しゃがみパンチ | 頭突きアッパー | 上に強い対空技 |
| しゃがみキック | ローキック払い | 当たると相手がダウン |
| 掴み | ボディスラム | 高ダメージ、掴みの間合いが広い |
| 必殺 | マッスルポーズ | 1発だけ耐えるスーパーアーマー、耐えたら反撃パンチ |
| →＋必殺 | ラリアット突進 | 前方へ突進。止められにくい |
| ↓＋必殺 | ヒップドロップ | ジャンプして着地の衝撃波。地上の相手に当たる |
| 必殺＋ガード | ジャイアントスイング | コマンド投げ。振り回して画面端まで投げる |
| ジャンプ中パンチ | 空中チョップ | 振り下ろす重いチョップ |
| ジャンプ中キック | ドロップキック | 両足で蹴る。当たり判定が大きい |

## 画像（ポーズ）

各キャラ、状態ごとに1枚をAI画像生成で用意する（1キャラ約22枚）。動きは伸び縮み・残像・効果線などコードの演出で補う。

| 分類 | ポーズ |
|---|---|
| 基本 | 待機、歩き、ジャンプ、しゃがみ、ガード |
| 通常技 | パンチ、キック、しゃがみパンチ、しゃがみキック、空中パンチ、空中キック |
| 掴み | 掴み（掴みに行く）、投げ（投げている最中） |
| 必殺 | 必殺（ニュートラル）、→＋必殺、↓＋必殺、超必殺 |
| 食らい | 被弾、ダウン |
| 演出 | 勝利ポーズ、超必殺のカットイン用の顔アップ、キャラ選択用の立ち絵 |

- ガードはしゃがみ中も同じポーズを使う（上下段がないため）
- 2P の色違いは画像を増やさず色味フィルタで作る
