# 03 技表

単位はフレーム（60fps、1F＝1/60秒）。

- 発生：ボタンを押してから当たり判定（掴み判定）が出るまで
- 持続：当たり判定が出ている間
- 硬直：当たり判定が消えてから動けるようになるまで
- 全体＝発生＋持続＋硬直
- 発生 4F なら、当たり判定は5F目から出る（1F目〜4F目が準備）。一般的な格ゲーの表記（発生に1F目を含める）とは1Fずれるので注意
- 重さ：のけぞり・ガード硬直・ノックバックの段階（軽・中・重）。値は `06_params.md`。掴みは対象外（—）
- ダメージは仮。体力はリン 850、ゴンゾー 1150

「遊んで決める」数値（無敵・アーマー・距離・のけぞりなど）は `06_params.md` に候補として置く。
決めきれていないことは `open-questions.md` に置く。

## 技の共通ルール

- 空中攻撃は1回のジャンプで1回だけ。硬直は着地した時点で打ち切り、代わりに着地の隙が少しある（ドロップキックだけ大きい）。隙の長さは `06_params.md`
- 掴み・投げ（超必殺のジャイアントスイングも含む）はジャンプ中の相手を掴めない
- 連拳は1発ガードしたら最後までガードが続く（途中で抜けられない）
- 連拳の5ヒットは1つの技として扱い、ヒット同士ではダメージ補正をかけない（補正がかかるのはキャンセルで繋いだ時）
- アーマーは打撃だけ耐える。掴み・投げは耐えられず投げられる
- 超必殺を出すと暗転（時間停止）してカットイン（キャラの顔のアップ）が入る

## 数字の考え方

- リンは「速い・軽い・手数」。発生はほぼ全てゴンゾーより速く、ダメージは低い
- ゴンゾーは「遅い・重い・一発」。打撃は遅いが、掴みとアーマー技で押し返す
- 超必殺のダメージは相手体力のおよそ2〜3割強（リン 250 / 1150 ≒ 22%、ゴンゾー 300 / 850 ≒ 35%）。パワー型の一発を重くした
