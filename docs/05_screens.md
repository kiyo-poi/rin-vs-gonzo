# 05 画面・演出

画面サイズは 1280×720。画面の流れは `01_concept.md` を参照。

## メニューの共通操作

- カーソル移動は各プレイヤーの方向キー、決定はパンチ、戻る・取り消しはガード
- タイトル・モード選択・結果画面は 1P・2P のどちらのキーでも操作できる
- Esc は対戦中のポーズ専用

## タイトル画面

- ゲームのロゴ、「PRESS START（パンチで開始）」
- 下部に 1P・2P のキー配置を常に表示

## モード選択

- 「2人対戦」「CPU戦」の2択
- CPU戦を選ぶと、続けて難易度（やさしい / ふつう / つよい）を選ぶ

## キャラ選択

- 1P・2P が同時に選ぶ。それぞれのカーソルを自分のキーで動かし、パンチで決定、ガードで取り消し
- 両者が決定したら対戦へ進む
- CPU戦では CPU のキャラはランダム
- 同じキャラを選べる（2P は色違い）
- 各キャラの立ち絵、名前、タイプ（スピード型 / パワー型）、技一覧と、2人分のキー配置を表示
- キャラはデータから並べるので、キャラを追加すると自動で選択肢が増える

## 対戦画面（HUD）

```
┌──────────────────────────────────────────┐
│ [1P 体力バー ■■■■■■■]  99  [■■■■■■■ 2P 体力バー] │
│  リン  ●○                         ○● ゴンゾー │
│                                          │
│                （対戦）                    │
│                                          │
│ [1P ゲージ ▮▮▮▮]                [▮▮▮▮ 2P ゲージ] │
└──────────────────────────────────────────┘
```

- 上部：左右に体力バー、中央にタイマー（99から減る）
- 体力バーの下：キャラ名と、ラウンドの勝利数（●が取ったラウンド）
- 下部の左右：超必殺ゲージ。満タンになると光る
- 体力バーは、減った分が一瞬赤く残ってから、ゆっくり縮む
- 連続技が繋がったら、当てた側に「2 HIT」と小さく表示

## 対戦中の演出

| 場面 | 演出 |
|---|---|
| ラウンド開始 | 「ROUND 1」→「FIGHT!」（約2秒）。表示中は動けない |
| ヒット | ヒットストップ＋ヒット火花＋擬音文字（「ドカッ」「バキッ」など）。重い技だけ画面が揺れる |
| ガード | ガード火花（ヒットと色を変える） |
| 相打ち | 両者の間に火花、「カキーン」 |
| 投げ抜け | 両者弾かれる、「パシッ」 |
| 超必殺 | 暗転＋カットイン（顔アップ）→ 技 |
| KO | 少しスロー＋「K.O.」→ 勝った側の勝利ポーズ |
| 時間切れ | 「TIME UP」→ 体力が多い側の勝利ポーズ |
| 引き分けラウンド | 「DRAW」 |
| 決着 | 「1P WIN」などを表示して結果画面へ |

- 演出の時間は `06_params.md` で調整する

## ステージ

- キャラごとに1つ（リン：中華街、ゴンゾー：プロレスのリング）
- 2P 側のキャラのステージで戦う。CPU戦では CPU のキャラのステージ
- ステージの横幅は画面幅の1.5倍（`04_system.md`）

## ポーズ画面

- メニュー：「再開」「キャラ選択へ」「タイトルへ」
- 2人分のキー配置と技一覧を表示
- Esc はどちらのプレイヤーが押しても止まる。Esc か「再開」で再開

## 結果画面

- 勝ったキャラの立ち絵と「1P WIN」（CPU戦では「YOU WIN」/「YOU LOSE」）
- メニュー：「再戦」「キャラ選択へ」「タイトルへ」

## 対応ブラウザ

- PC の Chrome・Edge・Safari・Firefox の最新版
- スマホは対象外（キーボードのみのため）
