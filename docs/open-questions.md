# 未決事項（Open Questions）

## 実際に試して決めるもの

- [ ] キー配置の確定（仮配置は 04_system.md）。2人で同時に押して、取りこぼすキーがないか実機で確認する

## 作りながら決めるもの

- [ ] 当たり判定の大きさ（技ごとの箱の大きさ）。画像ができてから合わせる

## 設計（08_architecture.md）

設計側で「推奨（ユーザー未確定）」として仮に決めたもの。問題なければ確定し、該当の仕様書に移す。

- [ ] フレームの数え方：攻撃の箱は「発生＋1」F目から出る（03 の「全体＝発生＋持続＋硬直」に合わせた。一般的な格ゲー表記とは1Fずれる）
- [ ] `06_params.md` に足す値：入力バッファ 6F、超必殺の同時押し猶予 3F、ジャンプの踏み込み 3F、ジャンプの高さ、斜めジャンプの横速度、画面端の余白 60px、ラウンド開始表示 120F、KO スロー 60F
- [ ] 空中ではガードできない
- [ ] 空中で食らったら落下して着地でダウン。落下中は追撃できない
- [ ] 掴めない状態：空中・のけぞり中・ガード硬直中・ダウン中・無敵中（ジャンプの踏み込み中は掴める）
- [ ] 掴み同士が同じフレームで届いたら両者弾かれる（投げ抜けと同じ扱い）
- [ ] アーマー技と打撃が同じフレームで当たったら、相打ちにせずアーマー側が耐えて当てる
- [ ] 超必殺はアーマーを無視して当たる
- [ ] 通常技 → 超必殺のキャンセルはできない
- [ ] ガードを押したまま攻撃ボタンを押すと技が出る（必殺＋ガードは押した瞬間が3F以内のときだけ超必殺）。ガード中は歩けない
- [ ] タイマーはラウンド開始表示・ヒットストップ・暗転・投げ演出・KO後は止める
- [ ] 掴み間合いは押し合いの箱の前端どうしの隙間で測る
- [ ] リンにもダッシュはない（02 でゴンゾーに「ダッシュなし」とあるが、ダッシュの入力は定義されていない）
- [ ] 対戦中にウィンドウのフォーカスが外れたら自動でポーズにする
- [ ] キャラデータは JSON で書く（TypeScript ファイルにはしない）
- [ ] 2P の色違いは画像の読み込み時に色を変えた画像を作る（Canvas の filter は使わない）
