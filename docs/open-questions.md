# 未決事項（Open Questions）

決めきれなかったこと、遊んでみないと決められないことを置く。決まったら該当の仕様書に移して、ここから消す。
数値の調整は `06_params.md` で扱うので、ここには置かない。

## 実際に試して決めるもの

- [ ] キー配置の確定（仮配置は 04_system.md）。2人で同時に押して、取りこぼすキーがないか実機で確認する
- [ ] 無料素材（効果音・BGM）の入手先とライセンス。候補は「効果音ラボ」「魔王魂」など。使う前に利用規約（クレジット表記の要否、改変の可否）を確認する

## あなたに決めてほしいもの

- [ ] キャラ名・技名の正式決定（今はすべて仮）

## 作りながら決めるもの

- [ ] 当たり判定の大きさ（技ごとの箱の大きさ）。画像ができてから合わせる

## 素材（07_assets.md）

- [ ] 絵柄の確定。推奨は「2〜3頭身のデフォルメ・アニメ調・太い輪郭線」（ユーザー未確定）
- [ ] キャラの見た目（髪型・服・色）の確定。07_assets.md のプロンプトの「キャラの部分」は仮
- [ ] 使う AI 画像生成ツールの決定と、生成画像をゲームに使って公開してよいかの規約確認
- [ ] 擬音文字・メニュー用の日本語フォントの決定（候補：Google Fonts の太い日本語フォント）。ライセンスを確認する
- [ ] ラウンドコール（「ROUND 1」「FIGHT!」「K.O.」など）を声にするか、ジングルで代用するか。推奨は声の素材が見つかれば声
- [ ] 素材ファイルを GitHub の公開リポジトリに置くことが、各素材サイトの規約で「再配布」にあたらないかの確認
- [ ] クレジット表記をゲーム内（タイトル画面の下部など）にも入れるか。推奨は README と assets/CREDITS.md に書き、規約で求められた場合だけゲーム内にも入れる
- [ ] ゲーム名とタイトルロゴの文字（今は仮ロゴでよい）
