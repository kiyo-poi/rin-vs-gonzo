# M2 対戦ルール Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 2人で1試合（ラウンド制）を最初から最後まで遊べて勝者が表示され、画面端に追い詰めて殴っても永久には殴り続けられないようにする（`docs/09_roadmap.md` の M2）。

**Architecture:** M1 の純粋な対戦ロジック（`src/logic/`）を広げる。キャラの状態を「技中なら何の技か」「ジャンプなら向き」を持つ形に直し、キック・斜めジャンプ・ノックバック・押し合い・距離の上限を足す。その上にラウンド・タイマー・勝敗を持つ `match.ts` を重ね、描画はカメラと仮の HUD を足す。調整値はすべて JSON（`06_params.md` の値）に置く。

**Tech Stack:** TypeScript（strict）、Vite、Vitest、Canvas 2D。依存は開発用の `typescript`・`vite`・`vitest` だけ。

## Global Constraints

- 画面は 1280×720。60fps 固定のフレーム単位で動く（`04_system.md`）
- ゲーム用ライブラリは使わない。依存は開発用の `typescript`・`vite`・`vitest` の3つだけ（`08_architecture.md` 1章）
- 対戦ロジック（`src/logic/`）の中で `Math.random()`・現在時刻・DOM を使わない（`08_architecture.md` 2.4）
- コード内に調整値を直接書かない。共通値は `src/data/params.json`、キャラ別の値はキャラデータ JSON に置く（`08_architecture.md` 6章）
- フレームの数え方：ボタンを押したフレームが技の1F目。攻撃の箱は「発生＋1」F目〜「発生＋持続」F目。全体F目の次のフレームから動ける。のけぞり・ガード硬直だけは当たったフレームに `frame: 0` で入れ、次のフレームが1F目（`08_architecture.md` 5章）
- 座標は「キャラの足元の中心」が原点、右向き基準、上がプラス（px）。ステージ座標は 0〜1920
- 数値（`06_params.md`・`03_moves.md`）：のけぞり 軽/中/重＝14/18/24F、ガード硬直＝10/13/17F、ノックバック＝20/35/60px（ガード時は1.2倍）、押す速さ＝歩き速度の50%、ステージ幅 1920、画面端の余白 60、2人の距離の上限＝画面幅1280−余白60×2＝1160、ラウンド開始表示 120F、決着表示 90F、1ラウンド 99秒＝5940F、2ラウンド先取、最大5ラウンド。キック（リンの旋風脚）＝発生8・持続3・硬直14・ダメージ50・中。前・後ろジャンプの横の速さ 6px/F
- 勝敗（`01_concept.md`）：体力0でラウンド負け。時間切れは残り体力の「割合」が多い方の勝ち。割合が同じ・同時KOは両者に1勝。先に2勝した方の勝ちだが、両者が同時に2勝に届いた（両者リーチからの引き分け）時は決着がつくまで続ける。5ラウンドで決まらなければ引き分け
- 向き：空中・技の途中では振り向かない。着地や技の終わりに振り向く（`04_system.md`）
- M2 の範囲外（M3 以降）：ヒットストップ、入力バッファ、キャンセル、ダメージ補正、掴み・必殺・超必殺・しゃがみ技・空中攻撃、空中で食らった時の落下とダウン（M2 も M1 と同じく「その場で地面に戻す」）、しゃがみガードの姿勢、ポーズ・タイトルなどの画面の流れ（M4）
- ユーザー向けの文章・コメントは日本語。識別子は英語
- コミットメッセージの末尾は必ず `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`（自分のモデル名に置き換えない）

作業ディレクトリはすべて `fighting-game/`（このリポジトリのルート）。テストは `npx vitest run <file>`、全体は `npm test`、型は `npx tsc`、ビルドは `npm run build`。

```ts
/** 攻撃の箱（ステージ座標）。持続中で、まだ当たっていない時だけ返す */
export function activeHitbox(f: Fighter): { box: Box; hit: HitData } | null {
  const st = f.state;
  if (st.name !== 'attack' || f.moveHasHit) return null;
  const move = f.char.moves[st.move];
  if (st.frame <= move.startup || st.frame > move.startup + move.active) return null;
  const hit = move.hits[0];
  return { box: toWorld(hit.box, f), hit };
}
```

```ts
import { clampX } from './fighter';
import type { Fighter, Params } from './types';

/** 押し合うのは地上にいる時だけ（空中なら重なってよい。相手を飛び越えられるように） */
function onGround(f: Fighter): boolean {
  return f.state.name !== 'air';
}

/**
 * 2人が重ならないように押し合う。prev は動かす前の2人（どちらが左か・誰が押したかを決めるのに使う）。
 * 片方だけが相手に向かって進んで重なったら、押された側は重なった分 × pushRate だけ動く。
 */
export function resolvePush(moved: [Fighter, Fighter], prev: [Fighter, Fighter], params: Params): [Fighter, Fighter] {
  if (!onGround(moved[0]) || !onGround(moved[1])) return moved;

  // どちらが左か。同じ位置なら、動かす前の並びで決める
  const left: 0 | 1 = moved[0].x !== moved[1].x ? (moved[0].x < moved[1].x ? 0 : 1) : prev[0].x <= prev[1].x ? 0 : 1;
  const right: 0 | 1 = left === 0 ? 1 : 0;
  const minGap = (moved[0].char.stats.pushWidth + moved[1].char.stats.pushWidth) / 2;
  const overlap = minGap - (moved[right].x - moved[left].x);
  if (overlap <= 0) return moved;

  // 相手に向かって進んだ側が「押した側」
  const leftPushed = moved[left].x > prev[left].x;
  const rightPushed = moved[right].x < prev[right].x;
  // 左の人が下がる割合
  let leftShare = 0.5;
  if (leftPushed && !rightPushed) leftShare = 1 - params.pushRate;
  if (rightPushed && !leftPushed) leftShare = params.pushRate;

  let leftX = clampX(moved[left].x - overlap * leftShare, params);
  let rightX = clampX(moved[right].x + overlap * (1 - leftShare), params);
  // 画面端で下がれなかった分は、もう片方が受け持つ
  const remaining = minGap - (rightX - leftX);
  if (remaining > 0) {
    if (leftX <= params.stage.edgeMargin) rightX = clampX(rightX + remaining, params);
    else leftX = clampX(leftX - remaining, params);
  }

  const result: [Fighter, Fighter] = [moved[0], moved[1]];
  result[left] = { ...moved[left], x: leftX };
  result[right] = { ...moved[right], x: rightX };
  return result;
}

/**
 * 2人の距離を「画面幅 − 画面端の余白 × 2」までにする（2人とも画面に収まるように）。
 * 超えた分は、このフレームに相手から離れる向きに動いた量に応じて戻す。
 */
export function limitDistance(moved: [Fighter, Fighter], prev: [Fighter, Fighter], params: Params): [Fighter, Fighter] {
  const max = params.screen.width - 2 * params.stage.edgeMargin;
  const excess = Math.abs(moved[0].x - moved[1].x) - max;
  if (excess <= 0) return moved;

  const away = [0, 1].map((i) => {
    // 相手から離れる向き（左にいるなら -1）
    const sign = moved[i].x < moved[1 - i].x ? -1 : 1;
    return { sign, amount: Math.max(0, (moved[i].x - prev[i].x) * sign) };
  });
  const total = away[0].amount + away[1].amount;
  const share = (i: number) => (total > 0 ? away[i].amount / total : 0.5);
  return [
    { ...moved[0], x: moved[0].x - away[0].sign * excess * share(0) },
    { ...moved[1], x: moved[1].x - away[1].sign * excess * share(1) },
  ];
}
```

### Task 5: ラウンド・タイマー・勝敗

**Files:**

**Interfaces:**
- Consumes: Task 4 の `createBattle(chars, params, xs?)`, `stepBattle`, `Battle`
- Produces:
  - `Params.round: { timeFrames: number; introFrames: number; endFrames: number; winsToWin: number; maxRounds: number }`
  - `interface RoundResult { reason: 'ko' | 'timeUp'; winner: 0 | 1 | null }`（null は引き分け）
  - `type MatchPhase = 'intro' | 'fight' | 'roundEnd' | 'matchEnd'`
  - `interface Match { chars; startXs?; battle; round; wins: [number, number]; phase; phaseFrame; timeLeft; lastResult: RoundResult | null; winner: 0 | 1 | null }`
  - `createMatch(chars: [CharacterData, CharacterData], params: Params, startXs?: [number, number]): Match`
  - `stepMatch(m: Match, inputs: [InputFrame, InputFrame], params: Params): Match`
  - `judgeRound(battle: Battle, timeLeft: number): RoundResult | null`
  - `timerSeconds(m: Match): number`（残り時間の表示。切り上げ）

試合の流れ：
- `intro`（ラウンド開始表示）：`introFrames` 回（120F）の間は対戦を進めない（入力は捨てる）。その次の呼び出しが対戦の1F目
- `fight`：毎フレーム `stepBattle` を進め、残り時間を1減らす。体力0（KO）か残り時間0（時間切れ）で `roundEnd` へ。KO と時間切れが同じフレームなら KO
- `roundEnd`（決着表示）：入った時に勝ち数を足す（勝者に1、引き分けなら両者に1）。`endFrames` 回（90F）止まったあと、試合が決まれば `matchEnd`、決まらなければ次のラウンドの `intro`（体力・位置・残り時間を戻し、勝ち数は残す）
- 試合の決まり方：どちらかが `winsToWin`（2）勝以上で、勝ち数が違えば多い方の勝ち。同じ（両者リーチからの引き分け）なら続ける。`maxRounds`（5）ラウンド目が終わっても決まらなければ引き分け（`winner: null`）
- `matchEnd`：何もしない（再戦は main.ts が新しい試合を作る）

```ts
import { createBattle, stepBattle, type Battle } from './battle';
import type { CharacterData, InputFrame, Params } from './types';

/** 1秒のフレーム数（タイマーの表示用。ゲームは 60fps 固定） */
const FRAMES_PER_SECOND = 60;

export interface RoundResult {
  reason: 'ko' | 'timeUp';
  /** 勝った側。null は引き分け（同時KO・時間切れで体力の割合が同じ） */
  winner: 0 | 1 | null;
}

export type MatchPhase = 'intro' | 'fight' | 'roundEnd' | 'matchEnd';

export interface Match {
  chars: [CharacterData, CharacterData];
  /** 各ラウンドの開始位置（省略時はステージ中央から左右に離れた位置） */
  startXs?: [number, number];
  battle: Battle;
  /** 今のラウンド（1始まり） */
  round: number;
  /** 取ったラウンドの数 */
  wins: [number, number];
  phase: MatchPhase;
  /** 今の段階に入ってからのフレーム数 */
  phaseFrame: number;
  /** ラウンドの残り時間（フレーム） */
  timeLeft: number;
  /** 直前のラウンドの結果 */
  lastResult: RoundResult | null;
  /** 試合の勝者。matchEnd の時だけ意味がある（null は引き分け） */
  winner: 0 | 1 | null;
}

export function createMatch(chars: [CharacterData, CharacterData], params: Params, startXs?: [number, number]): Match {
  return {
    chars,
    startXs,
    battle: createBattle(chars, params, startXs),
    round: 1,
    wins: [0, 0],
    phase: 'intro',
    phaseFrame: 0,
    timeLeft: params.round.timeFrames,
    lastResult: null,
    winner: null,
  };
}

/** 残り時間の表示（秒、切り上げ） */
export function timerSeconds(m: Match): number {
  return Math.ceil(m.timeLeft / FRAMES_PER_SECOND);
}

/** ラウンドの決着を調べる。決まっていなければ null。KO と時間切れが同じフレームなら KO */
export function judgeRound(battle: Battle, timeLeft: number): RoundResult | null {
  const [f0, f1] = battle.fighters;
  if (f0.health === 0 || f1.health === 0) {
    const winner = f0.health === 0 && f1.health === 0 ? null : f0.health === 0 ? 1 : 0;
    return { reason: 'ko', winner };
  }
  if (timeLeft > 0) return null;
  // 体力の最大値はキャラで違うので、残り体力の割合で比べる
  const r0 = f0.health / f0.char.stats.health;
  const r1 = f1.health / f1.char.stats.health;
  return { reason: 'timeUp', winner: r0 === r1 ? null : r0 > r1 ? 0 : 1 };
}

/** 試合を1フレーム進める */
export function stepMatch(m: Match, inputs: [InputFrame, InputFrame], params: Params): Match {
  const frame = m.phaseFrame + 1;
  switch (m.phase) {
    case 'intro':
      if (frame <= params.round.introFrames) return { ...m, phaseFrame: frame };
      // 開始表示が終わったフレームから対戦を始める
      return fight({ ...m, phase: 'fight', phaseFrame: 0 }, inputs, params);
    case 'fight':
      return fight(m, inputs, params);
    case 'roundEnd':
      if (frame <= params.round.endFrames) return { ...m, phaseFrame: frame };
      return nextRound(m, params);
    case 'matchEnd':
      return { ...m, phaseFrame: frame };
  }
}

function fight(m: Match, inputs: [InputFrame, InputFrame], params: Params): Match {
  const battle = stepBattle(m.battle, inputs, params);
  const timeLeft = m.timeLeft - 1;
  const result = judgeRound(battle, timeLeft);
  if (!result) return { ...m, battle, timeLeft, phaseFrame: m.phaseFrame + 1 };
  // 勝者に1勝。引き分けなら両者に1勝
  const wins: [number, number] = [
    m.wins[0] + (result.winner === 1 ? 0 : 1),
    m.wins[1] + (result.winner === 0 ? 0 : 1),
  ];
  return { ...m, battle, timeLeft, phase: 'roundEnd', phaseFrame: 0, lastResult: result, wins };
}

function nextRound(m: Match, params: Params): Match {
  const [w0, w1] = m.wins;
  const need = params.round.winsToWin;
  // 先に必要な勝ち数に届いた方の勝ち。両者が同時に届いた時（両者リーチからの引き分け）は続ける
  if ((w0 >= need || w1 >= need) && w0 !== w1) {
    return { ...m, phase: 'matchEnd', phaseFrame: 0, winner: w0 > w1 ? 0 : 1 };
  }
  if (m.round >= params.round.maxRounds) return { ...m, phase: 'matchEnd', phaseFrame: 0, winner: null };
  return {
    ...m,
    round: m.round + 1,
    battle: createBattle(m.chars, params, m.startXs),
    phase: 'intro',
    phaseFrame: 0,
    timeLeft: params.round.timeFrames,
  };
}
```

```ts
  const camX = cameraX(battle.fighters, params);

  const toScreen = (b: Box) => ({ x: b.x - camX, y: groundY - b.y - b.h, w: b.w, h: b.h });

  ctx.fillStyle = '#223';
  ctx.fillRect(0, 0, width, height);
  ctx.strokeStyle = '#334';
  ctx.lineWidth = 1;
  for (let x = 0; x <= params.stage.width; x += GRID) {
    ctx.beginPath();
    ctx.moveTo(x - camX, 0);
    ctx.lineTo(x - camX, groundY);
    ctx.stroke();
  }
  ctx.fillStyle = '#556';
  ctx.fillRect(0, groundY, width, height - groundY);

  battle.fighters.forEach((f, i) => {
    ctx.fillStyle = COLORS[i];
    for (const box of hurtBoxes(f)) {
      const s = toScreen(box);
      ctx.fillRect(s.x, s.y, s.w, s.h);
      if (f.state.name === 'guard' || f.state.name === 'blockstun') {
        ctx.strokeStyle = '#fff';
        ctx.lineWidth = 4;
        ctx.strokeRect(s.x, s.y, s.w, s.h);
      }
    }
    drawHealth(ctx, f, i, width);

    if (debug.show) {
      const active = activeHitbox(f);
      if (active) {
        const s = toScreen(active.box);
        ctx.strokeStyle = '#ff0';
        ctx.lineWidth = 2;
        ctx.strokeRect(s.x, s.y, s.w, s.h);
      }
      ctx.fillStyle = '#fff';
      ctx.font = '14px monospace';
      ctx.fillText(`${f.state.name} ${f.state.frame}`, f.x - camX - 40, groundY - f.y - 180);
    }
  });

  drawHud(ctx, match, params, width);

  if (debug.show) {
    ctx.fillStyle = '#fff';
    ctx.font = '16px monospace';
    ctx.fillText(`1P のキー: ${debug.keys.p1.join(' ')}`, 16, height - 40);
    ctx.fillText(`2P のキー: ${debug.keys.p2.join(' ')}`, 16, height - 16);
  }
}

/** 仮の HUD：タイマー・ラウンド・勝ち数（●）・画面中央の文言 */
function drawHud(ctx: CanvasRenderingContext2D, match: Match, params: Params, width: number): void {
  ctx.fillStyle = '#fff';
  ctx.textAlign = 'center';
  ctx.font = 'bold 40px sans-serif';
  ctx.fillText(String(timerSeconds(match)), width / 2, 62);
  ctx.font = '16px sans-serif';
  ctx.fillText(`ROUND ${match.round}`, width / 2, 90);

  ctx.font = '20px sans-serif';
  ctx.textAlign = 'left';
  ctx.fillText('●'.repeat(match.wins[0]), HEALTH_BAR.side, 80);
  ctx.textAlign = 'right';
  ctx.fillText('●'.repeat(match.wins[1]), width - HEALTH_BAR.side, 80);

  const message = phaseMessage(match, params);
  ctx.textAlign = 'center';
  if (message) {
    ctx.font = 'bold 72px sans-serif';
    ctx.fillText(message, width / 2, 300);
  }
  if (match.phase === 'matchEnd') {
    ctx.font = '24px sans-serif';
    ctx.fillText('パンチでもう一度', width / 2, 360);
  }
  ctx.textAlign = 'left';
}

/** 体力バー。1P は左、2P は右。減ると外側から縮む（中央側に寄せて描く） */
function drawHealth(ctx: CanvasRenderingContext2D, f: Fighter, index: number, width: number): void {
  const { width: barW, height: barH, top, side } = HEALTH_BAR;
  const x = index === 0 ? side : width - side - barW;
  ctx.fillStyle = '#400';
  ctx.fillRect(x, top, barW, barH);
  const w = (barW * f.health) / f.char.stats.health;
  ctx.fillStyle = '#fc3';
  ctx.fillRect(index === 0 ? x + barW - w : x, top, w, barH);
}
```

```ts
import { createFixedStep } from './core/loop';
import { controls, params, proto } from './data/data';
import { allCodes, buildInputFrame, emptyHeld, heldFromKeys, keysFor } from './input/inputFrame';
import { KeyboardState } from './input/keyboard';
import { createMatch, stepMatch, type Match } from './logic/match';
import type { InputFrame } from './logic/types';
import { drawFrame } from './render/render';

const canvas = document.getElementById('game') as HTMLCanvasElement;
const ctx = canvas.getContext('2d');
if (!ctx) throw new Error('Canvas 2D が使えません');

const keyboard = new KeyboardState(allCodes(controls));
keyboard.attach(window);

const newMatch = (): Match => createMatch([proto, proto], params);
let match = newMatch();
let prevHeld = [emptyHeld(), emptyHeld()];
const fixedStep = createFixedStep();

function tick(now: number): void {
  const steps = fixedStep(now);
  for (let i = 0; i < steps; i++) {
    const keys = keyboard.snapshot();
    const held = [heldFromKeys(keys, controls.p1), heldFromKeys(keys, controls.p2)];
    const inputs: [InputFrame, InputFrame] = [buildInputFrame(held[0], prevHeld[0]), buildInputFrame(held[1], prevHeld[1])];
    prevHeld = held;
    // 試合が終わったら、どちらかがパンチを押すと再戦（タイトルなどの画面の流れは M4）
    if (match.phase === 'matchEnd') {
      if (inputs[0].pressed.punch || inputs[1].pressed.punch) match = newMatch();
    } else {
      match = stepMatch(match, inputs, params);
    }
  }
  const keys = keyboard.snapshot();
  drawFrame(ctx!, match, params, {
    show: import.meta.env.DEV,
    keys: { p1: keysFor(keys, controls.p1), p2: keysFor(keys, controls.p2) },
  });
  requestAnimationFrame(tick);
}

requestAnimationFrame(tick);
```
