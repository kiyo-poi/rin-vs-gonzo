# M3a 通常技と体の動き Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** リンとゴンゾーを別々のキャラデータにし、通常技6種（立ち・しゃがみ・空中のパンチ・キック）、しゃがみガード、空中攻撃と着地の隙、ダウンと起き上がり、空中で食らった時の落下、相打ちを入れる（M3 を3回に分けた1回目）。

**Architecture:** M2 の純粋な対戦ロジックを広げる。技の「姿勢」（立ち・しゃがみ・空中）を技データに持たせ、食らいの箱は状態と姿勢から選ぶ。空中攻撃はジャンプの状態の中に「今出している空中技」を持たせ、ジャンプの動きはそのまま続ける。ダウン・空中やられ・着地の隙・相打ちの弾かれはそれぞれ状態として足す。キャラは `src/data/characters/*.json` を置くだけで増える形にする。

**Tech Stack:** TypeScript（strict）、Vite、Vitest、Canvas 2D。依存は開発用の `typescript`・`vite`・`vitest` だけ。

**Spec:** `docs/09_roadmap.md`（M3）、`docs/03_moves.md`（技表）、`docs/04_system.md`、`docs/06_params.md`、`docs/08_architecture.md`。M2 からの申し送りは `docs/open-questions.md` の「M3 で扱うこと」。

## Global Constraints

- 画面 1280×720、60fps 固定のフレーム単位。ゲーム用ライブラリなし、依存は `typescript`・`vite`・`vitest` だけ
- `src/logic/` の中で `Math.random()`・現在時刻・DOM を使わない
- 調整値はコードに直接書かない。共通値は `src/data/params.json`、キャラ別の値はキャラデータ JSON
- フレームの数え方：ボタンを押したフレームが技の1F目。攻撃の箱は「発生＋1」F目〜「発生＋持続」F目。全体F目の次から動ける。のけぞり・ガード硬直・ダウン・弾かれは当たったフレームに `frame: 0` で入れ、次のフレームが1F目
- 03 の通常技の数値（発生・持続・硬直・ダメージ・重さ）をそのまま使う。リン：ジャブ 4/2/8・30・軽、旋風脚 8/3/14・50・中、下段掌 5/3/10・30・軽、足払い 9/3/18・50・中・ダウン、空中掌打 6/6/8・40・中、飛び蹴り 7/8/10・50・中。ゴンゾー：チョップ 9/3/16・70・中、ビッグブーツ 13/4/20・90・重、頭突きアッパー 8/4/20・80・中、ローキック払い 14/4/24・100・重・ダウン、空中チョップ 9/6/12・70・中、ドロップキック 10/8/18・80・重・着地の隙 20F
- 06 の値：ダウン〜起き上がり 40F、起き上がりの無敵 6F、空中攻撃の着地の隙 4F（ドロップキックは 20F）、相打ちで弾かれた時の硬直 16F。ゴンゾーは体力 1150・歩き 3px/F・滞空 46F・ジャンプの高さ 170px・前ジャンプ 4px/F
- 04 の決まり：上下段なし（ガードで全部防げる）。空中ではガードできない。空中で食らったら落下して着地でダウン、落下中は追撃できない。空中攻撃は1回のジャンプで1回だけ。打撃同士が同じフレームで当たったら両方弾かれてダメージなし
- 申し送りの決定：しゃがみながらガードするとしゃがみの食らいの箱を使う（上下段はないので防げる攻撃は同じ）。ノックバックは「相手が自分のどちら側にいるか」で向きを決める
- 範囲外（M3b・M3c）：掴み・必殺・超必殺・キャンセル・補正・削り・アーマー・ゲージ・入力の先行受付・ヒットストップ
- 文章・コメントは日本語、識別子は英語。コミットの末尾は必ず `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

コマンド：`npx vitest run <file>`、`npm test`、`npx tsc`、`npm run build`。

## Review Focus

1. 空中攻撃を出したジャンプの着地のフレームに攻撃ボタンを押した時 → 技は出ず着地の隙になる（Task 3 のテスト）
2. 起き上がり無敵の境目 → 起き上がった最初の 6F は当たらず、7F目から当たる（Task 4 のテスト）
3. 空中攻撃を出したあとに空中で食らった時 → 着地の隙ではなく、落下してダウンになる（Task 4 のテスト）
4. 相打ちの片方が空中にいた時 → 空中の側は空中技だけ消えて落ち続け、普通に着地する。地上の側は 16F 弾かれる（Task 5 のテスト）
5. しゃがみガード中に空中攻撃・立ち技を受けた時 → 上下段がないので全部ガードになる（Task 2 のテスト）

  - `activeHitbox`：空中で `attack` がある時も、`attack.frame` で地上の技と同じ窓を使う
